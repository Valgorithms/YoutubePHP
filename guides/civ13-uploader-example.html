What made the run safe and repeatable

The human personally performed local Desktop PKCE consent for the approved project/channel and confirmed encrypted storage of exactly three protected environment secrets. No Google login was performed in Actions. The grant used only youtube.upload plus separately justified youtube.readonly . The environment required the owner reviewer, allowed that owner's self-review, disabled admin bypass and allowed only master . The setup helper created no environment and refused secret overwrite; gate variables stayed disabled throughout setup.

Untrusted gameplay/test producers and credential-free inspection were separated from trusted upload code. Both jobs used the reviewed default-branch dispatch commit. The secret-bearing job never checked out or executed PR scripts, treated artifact metadata as code, or decoded video. Actions and dependency references were pinned; secrets entered only the final trusted adapter step.

Two failures worth reproducing in integration tests

Historical PR provenance — PR3247. The original successful run reported pull_requests=[] despite belonging to the merged PR's exact game revision. The fix was limited to this approved historical import: require commit-to-PR API association, retained exact PR head SHA, both repository IDs, original successful CI and owner attestation/comment hash. Generic empty or conflicting associations still fail. Do not waive provenance globally or call the later packaging run a recorder/test run.

Empty reusable-workflow credentials — PR3248. Run 39443514193 stopped with a sanitized framework error although the three secret names existed. Missing named caller bindings resolved to empty credentials. The framework rejected empty client secret locally before OAuth/YouTube HTTP ; transport evidence and unchanged journal positively reconciled no transmission. That evidence justified a corrected bounded test without rotating credentials. The fix added named caller mappings, required callee declarations and nonempty credential preflight before PHP. The callee's protected environment still supplies the actual environment-scoped values. Secret-name presence never proves propagation.

Other generic errors do not imply this same safe failure point. Read the durable receipt and transport evidence first. Once an ID exists, verify that ID; do not insert a second video. An uncertain media outcome remains blocked until resolved.
