# YouTubePHP guides

YouTubePHP is an asynchronous ReactPHP client for the YouTube Data API v3.
The generated class reference documents the API surface. These guides explain
how to connect it to a reviewed application.

- [GitHub Actions uploader setup](github-actions-uploader.md): Google consent,
  protected credentials, workflow templates, library calls and required controller
  safeguards for a manually approved video upload.
- [Civ13 uploader case study](civ13-uploader-example.md): the exact tested source,
  successful run, durable receipt and fixes behind a working deployment.
- [Building and publishing these docs](publishing.md): the pinned phpDocumentor
  toolchain, local validation and bounded GitHub Pages deployment.

Source and issues: [Valgorithms/YoutubePHP](https://github.com/Valgorithms/YoutubePHP).
