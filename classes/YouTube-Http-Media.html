Media.php : 29

A file to upload: a video, a thumbnail, a caption track, a banner.

Uploads go in one request, as multipart/related when there is metadata to send beside the file and as the bare file when there is not. That suits thumbnails, banners and captions. A large video is better sent with Google's resumable protocol, which this library does not implement yet: a single request holds the whole file in memory and starts over if it fails.
