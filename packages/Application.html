Interfaces

ReauthorizerInterface
A way to get a brand-new grant when the existing one can no longer be refreshed: there is no refresh token, or Google revoked it.
TokenStoreInterface
Somewhere durable to keep the OAuth grant.
DriverInterface
Executes a single prepared {@see Request} and resolves with the raw {@see ResponseInterface}, success or error status alike. Retries, error mapping and quota are {@see Http}'s job, not the driver's.
HttpInterface
The transport {@see \YouTube\YouTube} sends every API call through.

PartException
A part could not be built: the class does not exist, or is not a part.
Factory
Builds {@see Part}s from raw API payloads.
React
The default {@see DriverInterface}: a non-blocking {@see Browser} from `react/http`.
BadRequestException
400: YouTube could not use the request as sent - a missing `part`, a message it will not post (`messageTextInvalid`), a malformed id.
ConflictException
409: the request conflicts with the resource's state - a moderator who is one already, say.
ForbiddenException
403: the account may not do this - moderate a chat it does not own, read a private resource. Subclasses name the 403s that mean something narrower.
HttpException
A request YouTube refused, or one that never got an answer.
LiveChatDisabledException
The broadcast has its live chat turned off.
LiveChatEndedException
The live chat has ended: the broadcast is over, so there is nothing more to read from it or post to it.
LiveChatNotFoundException
No live chat has that id.
MissingScopeException
The token was granted without a scope this call needs.
NotFoundException
404: no such resource.
QuotaExceededException
The day's quota is spent: Google said `quotaExceeded`, or the {@see Meter} refused the call before it was sent because it could not pay for it.
RateLimitedException
Too many requests, too quickly: Google's `rateLimitExceeded`, or a 429.
ServerException
A 5xx that kept failing after {@see \YouTube\Http\Http} retried it.
UnauthorizedException
401: the access token is missing, expired or revoked.
Http
Non-blocking transport for the YouTube Data API.
Media
A file to upload: a video, a thumbnail, a caption track, a banner.
Request
One prepared HTTP request: the verb, the absolute URL, the headers and the encoded body, plus the name of the API method it calls.
ResponseStream
The body of a server-streamed call, as a stream of parts.
BroadcastWatcher
Notices when the signed-in channel goes live, and when it stops.
ChatReader
Reads one live chat as it happens, and keeps reading through whatever the network does.
